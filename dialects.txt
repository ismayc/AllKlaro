# German dialect forms and common speech-recognition mis-hearings of them.
# Format:  dialect = standard German (gloss) [dialects it belongs to]
# Lines starting with "?" are AMBIGUOUS: they are real standard-German words
# too, so they are only hinted when the sentence also contains an
# unambiguous dialect marker ("nett" only means "net" (nicht) in a sentence
# that already says "nochemol").
#
# The trailing "[...]" names the dialects an entry belongs to, matching the
# style selector (berlin / hessian / worms; mexico / barcelona). An entry with
# no tag applies to EVERY dialect, which is the right answer for the enclitic
# contractions (haste, biste, kannste) that are colloquial across the whole
# language rather than regional.
#
# Tags decide two different things:
#   - which words get COLOURED in the heard text once a style is selected
#     (unambiguous entries), so choosing Berlinerisch does not paint a
#     Rhine-Hessian form red;
#   - which ambiguous entries may be glossed on their own under an asserted
#     dialect, where offering the Rhine-Hessian reading of "mehr" (= mer, wir)
#     to a Berlin speaker would be a new error rather than a fix.
# Forms genuinely shared between dialects carry several tags — under-tagging
# silently stops marking real dialect, so shared forms are tagged inclusively.

# --- Ambiguous: standard words that are often mis-heard dialect
#
# The Berlin group below is the first entry keyed on what speech recognition
# actually WRITES rather than on how the dialect is spelled, which is the only
# way any of this fires on audio. Evidence: on the real Berlin recording two
# independent decoders both produced "gekickt" and "kicke" for what the
# speaker said, and the next sentence gives the meaning away by using the
# standard word — "Ich kicke ja immer nicht. Meistens *guckt* der Arvid nach."
# Berlinerisch kieken = gucken, so "ich kieke ja immer nich" is "I never
# look", and both systems translated it as kicking a ball.
#
# Necessarily ambiguous: kicken is an ordinary German verb, so these may only
# be offered when the speaker's dialect is asserted, and hedged even then.
? kicke = kieke (gucke — Berlin "kieken" = schauen, nicht Fußball) [berlin]
? kickt = kiekt (guckt) [berlin]
? gekickt = jekiekt (geguckt) [berlin]
#
# The rest are Hessian / Rhine-Hessian forms (Berlinerisch has det/dit,
# nich and ma, not des, net and mol).
? des = das [hessian worms]
? nett = net (nicht) [hessian worms]
? mehr = mer (wir) [hessian worms]
? schoppe = Schoppen (a glass of cider/wine) [hessian worms]
? shoppe = Schoppen (a glass of cider/wine) [hessian worms]
? mol = mal [hessian worms]
